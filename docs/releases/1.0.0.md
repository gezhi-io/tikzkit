# TikZKit 1.0.0

The first major release of `@gezhi-io/tikzkit` renders supported TikZ
to SVG in Node.js and in the browser. No TeX installation is required
to run the JavaScript renderer.

**Upgrade from 0.1.x:** run `npm install @gezhi-io/tikzkit@1`. Keep using
`tikzToSvg`, `tikzToSvgAsync`, the `./fonts` entry point, or the
`tikz2svg` CLI. Node.js 20 or newer is required. Regenerate visual
snapshots: corrected paths and plots can produce different SVG geometry.

Selected changes since 0.1.7:

- Named inline coordinates can mark positions along lines and curves,
  label a junction, or select a ground shape. A relative `to` target no
  longer sends the following wire back to an earlier origin.
  [Before/after browser comparison](https://github.com/gezhi-io/tikzkit/blob/v1.0.0/docs/qa/2026-11-26-inline-coordinates.md)
- Ten Circuitikz ground symbols have native outlines and connection anchors.
  [Ground shapes and visual checks](https://github.com/gezhi-io/tikzkit/blob/v1.0.0/docs/qa/2026-11-26-circuitikz-grounds.md)
- PGFPlots draws soft-clipped fills against the actual path boundaries;
  steps, sampled bars, and plot-mark selection follow the PGF plot stream.
  [Fill-between examples](https://github.com/gezhi-io/tikzkit/blob/v1.0.0/docs/qa/2026-11-26-fill-between-boundaries.md)

Version 1.0 describes the public interface, not complete TikZ, LaTeX, or
PGFPlots support. Inspect diagnostics and use a TeX reference for important
diagrams. The tutorial, fixtures, and native reference images live on
GitHub; they are not included in the npm download.
