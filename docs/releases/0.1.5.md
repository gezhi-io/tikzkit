# v0.1.5

TikZKit remains experimental and is not a complete TeX replacement.

## Changes

- Bundle 53 MacTeX-derived font faces with provenance and licenses. SVGs embed
  used font families by default; `fontUrlPrefix` enables shared assets for both
  plain text and math. Public font exports are available at
  `@gezhi-io/tikzkit/fonts` and `@gezhi-io/tikzkit/fonts/*`.
- Fix clipped math limits, display-style size inflation, and font-relative
  `em`/`ex` dimensions. Remove the old KaTeX-derived font files.
- Replace dynamic expression execution with a restricted math parser. Bound
  loop expansion, report invalid expressions, and preserve PGFPlots' default
  nonfinite-sample discard behavior and explicit jumps.
- Correct sequential macro scoping, equivalent 3D box-ratio sizing, SVG
  definition isolation, Markdown fences, and CLI option validation.
- Bind acceptance to current source, implementation, and evidence; reject
  stale comparisons and numerically dependent references as independent proof.

## Verification And Limits

Focused checks pass 100/100. The full suite has 2,609 tests: 2,453 pass,
142 historical failures, and 14 skips, with no newly failing test names.
All 658 manifest cases convert without error-level diagnostics; this does not
mean all diagrams visually match LaTeX.

Complex formula widths and alignment, six special glyph slots, and parts of
the `svg-text` fallback remain incomplete. Embedded fonts increase SVG size;
shared font URLs reduce that duplication, but not the synchronous JS bundle.

See [font usage](../fonts.md) and the [repair report](../qa/2026-09-06-audit-repairs.md).
